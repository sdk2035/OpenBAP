1. Diagrama de Migración por Ingeniería Inversa con Rascal MPL para OpenBAP
El repositorio OpenBAP (Business Application Platform) contiene definiciones léxicas, formularios y flujos legacy. Para migrarlo a la arquitectura reactiva Low-Code, se define un pipeline de ingeniería inversa estructurado en Rascal MPL:

 [ Proyecto Legacy OpenBAP ] 
 (Formularios / Flujos XML/Java)
            │
            ▼
 ┌─────────────────────────────────────────────────────────┐
 │ 1. Extracción M3 & AST con Rascal MPL                    │
 │    (Mapeo de esquemas, entidades y reglas de negocio)  │
 └──────────────────────────┬──────────────────────────────┘
                            │
                            ▼
 ┌─────────────────────────────────────────────────────────┐
 │ 2. Inferencia & Enriquecimiento Semántico (IA)           │
 │    (Definición de Meta-Modelos JSON/XMI)                │
 └──────────────────────────┬──────────────────────────────┘
                            │
                            ▼
 ┌─────────────────────────────────────────────────────────┐
 │ 3. Generación AOT para UI Factory (GraalVM / Truffle)    │
 │    (Adaptadores BonitaBPM + OpenUI5 UI Controls)        │
 └─────────────────────────────────────────────────────────┘
Diagrama de Secuencia de Migración (PlantUML)

@startuml
actor "Dev/Architect" as Dev

Dev -> Rascal : Carga fuentes de OpenBAP (Java/XML)

Rascal -> AI : Exporta metadatos a XMI
AI -> AI : Mapea reglas a JSON Schema Low-Code
AI -> UI5 : Genera Vistas SAP OpenUI5 (Dynamic XMLViews)
AI -> Bonita : Inyecta REST Connector / Widget Extension
Bonita <-> UI5 : Ejecución reactiva de procesos de negocio

2. Plugin para BonitaBPM (Custom Widget / Integration Connector)
Este componente intercepta las tareas humanas de BonitaBPM e inyecta la UI Factory cargando dinámicamente las vistas generadas.

      "name": "processContract",

3. Plugin / Control Personalizado para OpenUI5
El control personalizado en OpenUI5 (openbap.ui.UIFactory) recibe la especificación JSON resultante de Rascal y renderiza controles enterprise de SAP/OpenUI5 en tiempo de ejecución.

openbap/ui/UIFactory.js
JavaScript
sap.ui.define([
    "sap/ui/core/Control",
    "sap/m/VBox",
    "sap/m/Input",
    "sap/m/Label",
    "sap/m/Button"
], function (Control, VBox, Input, Label, Button) {
    "use strict";

    return Control.extend("openbap.ui.UIFactory", {
        metadata: {
            properties: {
                schemaJson: { type: "object", defaultValue: null }
            },
            aggregations: {
                _layout: { type: "sap.ui.core.Control", multiple: false, visibility: "hidden" }
            },
            events: {
                submitProcess: { parameters: { payload: { type: "object" } } }
            }
        },

        init: function () {
            this.setAggregation("_layout", new VBox({ spacing: 2 }));
        },

        setSchemaJson: function (oSchema) {
            this.setProperty("schemaJson", oSchema, true);
            this._buildDynamicUI(oSchema);
        },

        _buildDynamicUI: function (oSchema) {
            var oContainer = this.getAggregation("_layout");
            oContainer.removeAllItems();

            if (!oSchema || !oSchema.fields) return;

            var oFormData = {};

            oSchema.fields.forEach(function (field) {
                oContainer.addItem(new Label({ text: field.label, required: field.required }));
                
                var oInput = new Input({
                    placeholder: field.placeholder || "",
                    change: function (oEvent) {
                        oFormData[field.name] = oEvent.getParameter("value");
                    }
                });
                oContainer.addItem(oInput);
            });

            oContainer.addItem(new Button({
                text: oSchema.submitText || "Enviar a BonitaBPM",
                type: "Emphasized",
                press: function () {
                    this.fireSubmitProcess({ payload: oFormData });
                }.bind(this)
            }));
        },

        renderer: function (oRm, oControl) {
            oRm.openStart("div", oControl);
            oRm.openEnd();
            oRm.renderControl(oControl.getAggregation("_layout"));
            oRm.close("div");
        }
    });
});
